Drake's Audiobookshelf in CasaOS

Once the operator has supplied the verified image and private web address:

1. In CasaOS, open App Store → Custom Install → Import → Docker Compose.
2. Paste the supplied Compose file and confirm the existing Audiobookshelf address.
3. Click Install. Open “Drake's Audiobookshelf” and use your existing account.

No books, accounts, or library folders need to be copied. The reserved host port is 13379.

Automatic updates need a separate, one-time host updater installation by the operator. They are not enabled by importing the app. This template currently contains example addresses; the operator must fill them before Jesse receives it.
